# chiefrom-report

頭沐｜CHIEFROM 門店每日回報系統＋沉睡顧客關懷系統。

- 前端：本 repo 的 `index.html`（GitHub Pages）
- 後端：Google Apps Script（`Code.gs`、`Care.gs`）——**不放在這個 repo**
- 資料：私人 Google 試算表

> ⚠️ 本 repo 是 Public。客人資料、神美匯出檔、後端程式都不能放進來（見 `CLAUDE.md`）。

## 角色

| 角色 | 可以做什麼 |
|---|---|
| 總部 | 每日總覽、紀錄、月報、月結（上傳神美、對帳、業績報表）、關懷管理（總覽、人員、設定）、門店畫面、零用金補入、刪除紀錄 |
| 經理 | 所有門店的每日總覽、紀錄、月報、關懷總覽；月結的上傳神美與對帳（可標記已確認無誤）。看不到業績報表與獎金，不能填寫、刪除或管理人員 |
| 店長 | 每日回報、零用金支出、紀錄、關懷總覽（只看自己負責的店；可負責多間店，畫面上切換） |
| 客服 | 關懷頁：非儲值沉睡客，一次一位 |
| 養護師 | 關懷頁（分配給自己的儲值沉睡客，一次一位）＋自己那間店的每日回報、零用金支出、回流訊息（前後照對比圖＋公版訊息） |

## 上線步驟

### 1. 建立 Google OAuth Client ID（Google 帳號登入用）

1. 打開 <https://console.cloud.google.com/>，左上角選擇或建立一個專案（例如「chiefrom-report」）。
2. 左側選單「API 和服務」→「OAuth 同意畫面」：
   - User Type 選「外部」→ 建立
   - 應用程式名稱填「頭沐門店系統」，使用者支援電子郵件和開發人員聯絡資訊填自己的 Gmail → 儲存
   - 「發布狀態」按「發布應用程式」（只用到 email 基本資料，不需要 Google 審查）
3. 左側「憑證」→「建立憑證」→「OAuth 用戶端 ID」：
   - 應用程式類型：**網頁應用程式**
   - 已授權的 JavaScript 來源：`https://torikuo314.github.io`
   - 「已授權的重新導向 URI」留空 → 建立
4. 複製「用戶端 ID」（長得像 `1234567890-xxxx.apps.googleusercontent.com`）。
   - Client ID 不是秘密，可以放在前端；**用戶端密鑰（Client secret）用不到，不要放任何地方。**

### 2. 設定 Apps Script（後端）

1. 打開試算表 →「擴充功能」→「Apps Script」。
2. 新增檔案 `Care.gs`，貼上 `Care.gs` 的內容（向開發者索取，不在 repo 裡）。
3. 依 `INTEGRATION.md`（與 Care.gs 一起提供）修改 `Code.gs`：改用 Google 登入、移除 PIN。
4. 左側齒輪「專案設定」→「指令碼屬性」→ 新增：
   - `OAUTH_CLIENT_ID`＝第 1 步的用戶端 ID
5. 在編輯器上方選擇函式 `careSetup` → 執行（第一次會要求授權）。會建立 `人員`、`關懷名單`、`關懷紀錄`、`勿擾名單`、`操作紀錄`、`關懷設定` 分頁與每日凌晨 3 點的排程。
6. 「部署」→「管理部署作業」→ 編輯 → 版本選「新版本」→ 部署（網址不變）。

### 3. 填寫「人員」分頁（切換登入前一定要先做）

| Email | 姓名 | 角色 | 店家 | 神美名稱 | 在職 |
|---|---|---|---|---|---|
| 每個人的 Google 帳號 | 顯示用 | 總部／經理／店長／客服／養護師 | 本館／散步二館／台南；店長可填多間，用「、」分隔（總部、經理、客服留空白） | 養護師必填，神美「工作人員」上的名字 | 是／否 |

- 店長的「店家」要和既有每日回報使用的門店名稱一致。
- 之後可以在系統的「關懷 → 人員」新增或修改；改成離職時，她名下未結案的客人會自動重新分配。

### 4. 前端

把 `index.html` 裡的 `GOOGLE_CLIENT_ID` 改成第 1 步的用戶端 ID，commit 後 GitHub Pages 會自動更新。

## 安全提醒

- 試算表**不可**開啟「知道連結的任何人」分享，只分享給需要的總部人員。
- Google 帳號與 GitHub 帳號都要開啟**兩步驟驗證**。
- 關懷名單只透過後端一次給一位；沒有任何 API 可以列出名單。所有登入、領取、送出、匯入、匯出都記錄在「操作紀錄」。
- 結案滿 6 個月（可在設定修改）的客人，每日排程會清除手機與姓名；「勿擾名單」永久保留。
